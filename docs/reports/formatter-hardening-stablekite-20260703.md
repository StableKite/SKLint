## Политика fixes

`format`, `format --check`, `check --fix` и VSCode-команда «исправить всё безопасное» применяют только fixes с `safe = true`. Шаблоны, требующие смыслового текста, и неоднозначные преобразования могут оставаться отдельными явными code actions, но не участвуют в массовом форматировании.
